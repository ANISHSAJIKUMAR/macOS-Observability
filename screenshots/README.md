## How to Capture

### Mac Screenshots:
- `Cmd + Shift + 4` then `Spacebar`: Window screenshot (with shadow)
- `Cmd + Shift + 4`: Select area
- Hold `Option` after Spacebar: Window without shadow

### Best Practices:
- Use full screen or large window (~1600px)
- Dark theme looks more professional
- Ensure data is visible (not empty graphs)
- Save as PNG (not JPG)
