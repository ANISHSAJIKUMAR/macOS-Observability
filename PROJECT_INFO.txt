Project Name: macOS Observatory
Repository: github.com/ANISHSAJIKUMAR/macos-observatory
Tagline: Your complete macOS observation platform

Description:
macOS Observatory is a production-grade observability platform built specifically
for macOS. Monitor 100+ metrics including system resources and Mac-specific data
like battery health, CPU temperature, and WiFi signal strength. Features automatic
service healing, one-command deployment, and beautiful Grafana dashboards.
