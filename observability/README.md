# Observability Stack (macOS)

Local monitoring stack using Prometheus, Grafana, Loki, Promtail, and node_exporter.

## Components
- Prometheus (http://localhost:9090)
- Grafana (https://localhost:3000)
- Loki (http://localhost:3100)
- node_exporter (http://localhost:9100/metrics)
- Promtail

## Purpose
- Collect macOS host metrics
- Collect and query logs
- Visualize metrics/logs in Grafana
