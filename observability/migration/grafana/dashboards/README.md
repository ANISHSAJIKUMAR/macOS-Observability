# Dashboard Backups

## Purpose
JSON exports of Grafana dashboards for backup/restore.

## Files
- `mac-system-all.json`
- `mac-network.json`
- `mac-info.json`
- `all-metrics-full.json`
- `exec-summary.json`
- `overview.json`
- `prometheus-self.json`

## Usage
Import via Grafana UI:
- Dashboards → Import → Upload JSON

## Common Changes
- Edit dashboards in Grafana and re‑export JSON here
- Rename dashboards in Grafana for interview/demo clarity
